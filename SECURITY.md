# Security Policy

## Supported versions

Before 1.0, security fixes are made on the latest release and the `main` branch.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/allenday/agent-surface/security/advisories/new)
and include affected versions, impact, and a minimal reproduction when possible.

Never include live credentials, tokens, or sensitive user data in a report or test fixture.
